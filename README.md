# ConnectivityQualityManagement

Working repository of the CAMARA Sub Project [Connectivity Quality Management](https://lf-camaraproject.atlassian.net/wiki/x/hAClB) for topics that span the Sub Project's API repositories. No CAMARA Service APIs are developed in this repository.

* Sub Project [wiki page](https://lf-camaraproject.atlassian.net/wiki/x/hAClB)

## Scope

* Traversal topics of the Connectivity Quality Management Sub Project that are not specific to a single API repository
* Initial focus: joint white paper across [QualityOnDemand](https://github.com/camaraproject/QualityOnDemand), [QoSBooking](https://github.com/camaraproject/QoSBooking), and [DedicatedNetworks](https://github.com/camaraproject/DedicatedNetworks)
* Started: May 2026
